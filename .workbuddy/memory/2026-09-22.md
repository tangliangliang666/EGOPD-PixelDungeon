### 脚本自身踩的坑（写进 skill 了）

1. **删掉带括号的代码块后不能断言「花括号数不变」** ⇒ 应断言「各减 1 且整体仍平衡」（`switch{}` 自带一对）。
2. **补丁脚本要幂等**：锚点消失后重跑会直接崩 ⇒ 写成「已应用则跳过」，否则第二次跑必红。
3. **`#` 注释行剥壳要 `l[1:].lstrip()`**：`# actors.xxx=` 的 `#` 后有一个空格，用 `l[1:]` 匹配不到键。
4. **别用 Python 的 `%` 去模拟 Java `String.format`**：Java 对**多余实参忽略**，Python 直接抛 `TypeError`
   ⇒ 会造出**假红**；`%s` 不足/非法转换才是两边一致的部分。真要判「裸 `%`」就直接正则
   `%(?![bBhHsScCdoxXeEfgGaAnt%])`，并把 Java 侧真实行为交给真装载脚本实测。
5. **正则别用 `[^)]*` 抓含嵌套括号的实参**（`Messages.get(this,"k",titleCase(hero.name()))` 会被内层 `)` 截断）
   ⇒ 改抓「整条语句」（`msg1 \+= Messages\.get\(this, "intro_hero", (.*?)\);`）。
