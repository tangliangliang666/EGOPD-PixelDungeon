## 新神器「复仇账簿」+ 指虎 + 封印之剑系列改造 + 中指长兄专属开局

### 复仇账簿 RevengeLedger（百分比充能神器）
- `items/artifacts/RevengeLedger.java`，`image = ARTIFACT_REVENGE_LEDGER = xy(1,41)`（13×16）。
- **百分比充能范式**：`chargeCap = 100` ⇒ `Artifact.status()` 自动走 `%d%%` 分支，无需自写显示逻辑；`charge` 存 0~100 的 float。
- 充能入口（静态方法，宿主钩子调用）：`onHeroDamaged(hero, hpLost)` = hpLost/maxHP×100；`onEnemyKilled(hero, mob)` = mob.HT/maxHP×100×0.1。击杀侧 `mob.HT` **必须在 `super.die()` 前读**。
- Rancor（仇怨）buff：**非静态内部类**（Bundle 跳过 ⇒ 由神器手动 `storeInBundle/restoreFromBundle` 存 `BUFF` 键），`activeBuff` 字段持有，`activate()` 重挂、`doUnequip()` detach。
- `Rancor.act()` 每回合 `charge = max(0, charge-2)`；归零 → `detach()` + 日志。`Hero.STR()` 里 `if (buff(Rancor.class)!=null) strBonus += 12`（拉取式，不推送）。
- `passiveBuff()` 必须返回一个占位 buff（`ledgerRecharge` 只 `spend(TICK)`），否则激活链 NPE。
- buff 图标 `BuffIndicator.RANCOR = 113`（紧邻 `TEAR_SWORD=112`）；`buffs.png` 与 `large_buffs.png` 第 113 格都已画。
- 宿主钩子：`Hero.damage()` 里加 `preHPOnly/postHPOnly`（**纯 HP，不含护盾**）快照，`effectiveDamage` 结算后 `RevengeLedger.onHeroDamaged`；`Mob.die()` 英雄击杀分支加 `RevengeLedger.onEnemyKilled`。
