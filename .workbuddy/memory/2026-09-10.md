### 核心调研结论

- **项目此前无任何自定义附魔**——`items/weapon/enchantments/` 13 种、`items/armor/glyphs/` 13 种全为原版，本次是首创。
- **基类**：`Weapon.Enchantment`（`items/weapon/Weapon.java:547`）——抽象方法 `proc(Weapon,Char,Char,int)` 与 `glowing()`；分组数组 `common/uncommon/rare/curses` + `typeChances{50,40,10}`；`Bundlable` 默认空实现。
- **proc 调用链**：`Char.attack → attackProc → Hero.attackProc:1653 wep.proc → Weapon.proc:137 → enchantment.proc`。`Weapon.proc` 有 MagicImmune 门控 / 松脂涂层覆盖 / 圣宣分支 / 三一魂附 四条路径。`BodyArtWeapon.proc:99` 在主附魔后再依次跑 `extraEnchants`。
- **附魔强度**：`procChanceMultiplier(attacker)` → `genericProcChanceMultiplier`（public static）→ 含奥术戒指 `RingOfArcana.enchantPowerMultiplier`（`1.175^等级`，每级 +17.5%）+ Berserk / RunicBlade / Smite / ElementalStrike / SpiritBlades / StrikingWave / FuriosoReplica / BrandWorkshop·WaxWing 共 9 项加成。原版范式：`procChance=(lvl+1)/(lvl+N)*multiplier`，`powerMulti=max(1,procChance)` 兼任"强度"。
- **光效**：`ItemSprite.Glowing(color[, period])`，`ItemSprite.draw():522` 按 phase/period 脉冲染色；`Weapon.glowing():540` 负责可见性门控（未鉴定诅咒不显示）。原版 13 附魔色值已全部抄录进文档对照表。
- **buff 型附魔样板** = `Kinetic`：`KineticTracker`（VFX_PRIO 一次性标记）+ `ConservedDamage`（真状态，`act()` 每回合衰减、`iconTextDisplay()` 显数值、PRESERVED_DAMAGE 存档键）。**"随时间积累"= 自定义 buff 覆写 `act()` 里累加 + `spend(TICK); return true;`**。
- **束缚/扎根现成件**：`Cripple`（残废，10f，`Char.speed()` 里 `speed/=2f`，图标 23）、`Roots`（扎根/缠绕，5f，`target.rooted=true` 禁移动、飞行免疫，图标 11）、`Slow`（10f，TIME 图标）。**先例**：`Binding.java:66-97` 的 `restrain()` 已实现"无残废→10f残废；已有残废→5f扎根（刷新）"，可整段搬成附魔逻辑。
- **`Buff.affect` 两重载**：`affect(Char,Class)` 任意 buff；`affect(Char,Class,float)` 仅 `FlavourBuff`（固定时长 debuff 走这个）。
- **buff 图标分配现状**：`BuffIndicator` 0~111 已用（最大 `PALERMO_SWORD=111`），**112~126 可用**，127=NONE；另有历史空号 93/94/107。

## 🕐 修复：饰物「沉默的代价」未进随机池（2026-09-10）

**症状**：饰物在调试台「饰品」标签页能生成，正式流程却永远遇不到。

**根因**：`SilentPrice.java` 与文本键都写好了，但**没有登记进 `Generator.TRINKET.classes`** —— vanilla 饰物唯一的随机池（17 个原版饰物，缺它）。

**修复**（`items/Generator.java` 三处）：
- import `SilentPrice`（ShardOfOblivion 与 ThirteenLeafClover 之间）；
- `TRINKET.classes` 尾部追加 `SilentPrice.class`（17 → 18）；
- `TRINKET.defaultProbs` 同步追加权重 1（18 项对齐，已核验）。

**连带自动生效**：`Catalog.TRINKETS.addItems(Generator.Category.TRINKET.classes)` → 图鉴 / 博物馆饰品区自动收录；`TrinketCatalyst` 三选一、`ScrollOfTransmutation` 蜕变均走 `Generator.random(Category.TRINKET)`。

**教训**：调试台标签页走的是**递归扫描包目录**，会自动发现新类；而正式随机池是**显式数组**。两者机制不同 → "调试台能生成"绝不能当作"已接入掉落"的证据。已写入 `MEMORY.md` 新增饰物接入清单。

## 逻辑工作室：直接攻击改射击（2026-09-10 追加）

**需求**：远程形态 LogicStudio 的快捷栏被 `defaultAction() = MorphWeapon.AC_MORPH`（切换）占用，
想射击只能开背包选"射击"；且点按敌人走的是通用**近战**结算（有 `RCH = 9` 能远程够到但不发弹丸）。
改为：**直接攻击即射击**。

**改动**：
- `Hero.actAttack`（普通攻击唯一汇聚点）在 `isCharmedBy/isAlive/canAttack/invisible` 校验、
  且「攻击性护盾」天赋结算**之后**插入接管：
  `if (belongings.attackingWeapon() instanceof LogicStudio){ shootAt(...); attackTarget=null; curAction=null; return false; }`
  —— `curAction = null` 是关键，否则 `cast()` 收尾的 `spendAndNext`（会 `next()`）之后
  英雄再 `act()` 会读到同一个 `HeroAction.Attack` → 无限连射。
- `LogicStudio.shootAt(Hero, int)` = `new Shot().cast(hero, target)`（与 AC_SHOOT 同链路，AC_SHOOT 保留）。
- `Shot.adjacentAccFactor` 覆写：相邻返 1×、非相邻沿用 1.5×（取消投掷物的 0.5× 贴脸惩罚，
  否则平砍改射击后贴脸变 50% 命中）。
- `LogicStudio.desc()` 追加"直接攻击即为射击。"。

## 溶解之爱精灵图重制 + 爱慕「赠予」玩法（2026-09-10 追加 4）

用户重绘了两张溶解之爱贴图，要求替换旧配置并新增交互玩法。

- **新贴图**（`Assets.Sprites.LOVENEW` / `LOVEANGER`，旧 `Sprites.LOVE` 已删）：
  - `lovenew.png` 单帧 16×24、每行 10 帧共 4 行 = **两组**（组内 2 行，步长 `LOVENEW_COLS*2=20`）；组内帧序
    1 默认 / 2 待机回头 / 3 移动 / 4-6 攻击 / 7-10 死亡 / 11 尴尬 / 12 快乐 / 13 焦虑 / 14-15 黑化。**默认第一组**。
  - `loveanger.png` 单帧 20×24、单行 6 帧：1 默认 / 2 移动 / 3-4 攻击 / 5-6 死亡（反噬形态，无表情/黑化）。
- **`MeltingLoveSprite` 重写**：`PALETTE_A/B` + `configureLove()`（组基址 `b=palette*20`）与 `configureAnger()`；
  待机仿 `GuardSprite` 回头范式 `0,0,0,1,0,0,1,1`；`hold()` 定格式表情（同帧重复 8 次、fps4，播完回待机）；
  焦虑为 fps2 循环持续表情；黑化两帧 → `onComplete` 自动 `configureAnger()`。
  覆写 `link()`（按怪物持久状态重建形态）/`idle()`（焦虑期间用焦虑帧）/`play()`（黑化期间防打断，die 例外）。
  **换贴图宽度 16→20 后须 `place(ch.pos)` 重对齐格子**。
- **`MeltingLove`**：新增字段 `imageGroup` / `angry` + Bundle 键 `image_group` / `anger`（旧档缺键默认 0/false）；
  `summon(...)` 增加 `palette` 形参；`betray()` 置 `angry=true` 并 `darkenThenAnger()`；对外 `palette()/setPalette/isAngry/playEmote/beginAnxious/endAnxious`。
- **`Admiration` 赠予**：`AC_GIFT`（仅 `isEquipped` 时出现，`actionName`「赠予」）→ `giftSelector`（只可选
  `Potion`/`Scroll`，无存活忠诚溶解之爱则提示拒绝）→ `giveToLove` 五分支：嬗变卷轴（消耗 + `Speck.CHANGE`
  粒子 + `Sounds.READ` + **组 A/B 往返**）；其它卷轴→尴尬；拒绝类药水（力量/根骨/经验/神圣启示，`REFUSE_POTIONS`）
  →快乐且返还；负面药水（`NEGATIVE_POTIONS` 9 种）→尴尬且返还；其余正面药水→消耗 + `applyPotionEffect` 逐种映射
  （治疗/迅捷/隐身/飘浮/净化/羽落/解咒/护盾/奥术护甲/大地护甲/疾跑…其余统一治疗+回血）+ 快乐。
  `lovePalette` 进 Bundle（`love_palette`），`summonLove` 传入 → **嬗变形态跨死亡/重召保持**。
- **焦虑 / 反噬表现**：`doUnequip` 与 `BetrayalTimer.act()` 调 `love.beginAnxious()`（移动中只置标志，由
  `Sprite.idle()` 接上）；`BetrayalTimer.detach()` 调 `endAnxious()`；倒计时归零 `betray()` 播黑化→anger 配置。
  **黑化/换形态不改 `palette`**，故不影响叛变前处于第一组还是第二组。
