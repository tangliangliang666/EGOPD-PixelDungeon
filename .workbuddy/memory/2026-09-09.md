## 新增四阶武器：し协会的暗杀刃（ShiAssassinsBlade）

- **位置/外观**：`items/weapon/melee/ShiAssassinsBlade.java extends MeleeWeapon`；图标常量 `ItemSpriteSheet.SHI_ASSASSINS_BLADE = xy(13, 32)`，15×16，`assignItemRect(15,16)`。`tier=4`，`hitSound=HIT_STAB`、pitch 0.9。**xy(13,32) 槽位经像素级确认（自写 PNG 解码器）当前完全空白**，与 DOCUMENTS 组（仅用 +0..+6 = col1..7）无冲突。
- **面板**：`min(lvl)=4+4L` / `max(lvl)=24+2L`——最小成长高于最大成长；+10 收敛为固定 44（恒等于 max → 每击必 +44），+11 起 min>max 反转属超 +10 极端情形。
- **效果**：
  1. **匕首类偷袭加成**（参考暗杀之刃，band=50%）：`damageRoll` 中仿 vanilla AssassinsBlade/Mob.surprisedBy 的偷袭掷骰区间 `min + round(diff×0.50f) ~ max`；
  2. **掷出最大伤害 +44**：基础掷骰 == max() 时，在 augment 与 exStr 之后平加 `MAX_DMG_BONUS=44`（恒字面 44）。偷袭把区间抬高到 max 附近，触发爆发概率更高。
- **不掉链设计**：自包含覆写 damageRoll 而**非** `extends AssassinsBlade`，避免顺带继承其决斗家「潜行」武技与文本链（用户未请求武技，与 DiamondSword/WillBlade 等自定义武器一致无武技）。
