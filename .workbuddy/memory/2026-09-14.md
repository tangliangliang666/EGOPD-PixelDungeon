## 封印之剑改造：初始形态 + 锁定双手 + 决斗家式主副切换 + 快捷栏解封

### 需求（用户原话要点）
① 初始携带**封印之剑**形态（不再直接给莱瓦汀）；
② 调研决斗家主副武器体系，让莱瓦汀系列**无法从武器栏被换下**，只能切换到**副手**；**副手形态即还原为封印之剑**；
③ 让莱瓦汀系列**在快捷栏点击即可切换形态**。
追问确认：②的触发方式＝**照决斗家那样，用右下角类似技能的按钮**切换；副手**也锁定**（全程绑在双手之间）。

### 调研结论（决策依据）
- SPD 的主副手＝`Belongings.weapon` / `secondWep`；Champion 的交换是 `MeleeWeapon.Charger.doAction()`
  ——**直接对调两个槽位引用**，完全不碰 `doUnequip`。
- **`doUnequip` 是「离手」的唯一汇聚点**：`EquipableItem.doDrop()`（`!isEquipped || doUnequip(hero,false,false)`）、
  `cast()`、`KindOfWeapon.doEquip()`/`equipSecondary()`（都要先让槽位武器 `doUnequip` 成功）全靠它的返回值。
  ⇒ 返回 false 就能一处锁死「取消装备/丢弃/投掷/被顶替」。
- **两个绕过 doUnequip 的例外**：①`DisarmingTrap` 直接 `hero.belongings.weapon = null`（已加 `instanceof` 排除）；
  ②安卡失物走 `Belongings.lostInventory()`（`weapon()`/`secondWep()` 靠 `keptThroughLostInventory()` 决定是否隐身）⇒ 覆写为 true。
- 快捷栏点击 = `Item.execute(hero)` → `defaultAction()`；先例 `MorphWeapon → AC_MORPH`、`MagesStaff → AC_ZAP`。
  注意 `defaultAction()==null` 的武器根本**进不了快捷栏**（`QuickSlotButton.itemSelector` 过滤）⇒ 兜底 `AC_EQUIP`。
- `ActionIndicator` 是**全局单槽**，所有候选（Berserk/Combo/Charger/ScorchingWound…）都是 `Buff implements ActionIndicator.Action` 互相抢。

### 实现
- `items/weapon/melee/SealedSwordBase.java`（重写）：
  - `doUnequip` 在槽内一律拒绝（`bound` 提示）；`keptThroughLostInventory() → true`；
  - `AC_SWAP` + `swapHands(Hero)`：直接对调槽位引用；**主手→副手时用 `copyOf(this, SealedSword.class)` 造同数据封印态替身**，
    并同步改快捷栏引用 + `activate` + `operate`/`UNLOCK` 音效 + `ActionIndicator`/`AttackIndicator`，**不花回合**；
  - `SwordSwap`（**静态嵌套 Buff，implements ActionIndicator.Action**）：`activate()` 挂载、`act()` 自检 + **仅在 `ActionIndicator.action == null` 时占位**（让位给狂暴/连击）、`detach()` 清 action；图标复用 `HeroIcon.WEAPON_SWAP`(109)、色 `0x5500BB`、不占 buff 条；
  - `defaultAction()`：主手→`AC_UNSEAL`／副手→`AC_SWAP`／背包→`super` 为 null 时兜底 `AC_EQUIP`；
  - `AC_UNSEAL` 改为**仅主手有效**（副手恒为封印态），动作菜单保留；删掉旧的「卸下即还原」逻辑（已被锁定取代）。
- `actors/hero/HeroClass.java`：`initMiddleFinger` 初始物 `Laevateinn` → `SealedSword`；import 同步替换。
- `levels/traps/DisarmingTrap.java`：加 `!(weapon instanceof SealedSwordBase)`。
- 本地化：新增 `sealedswordbase.{ac_swap,need_main_hand,bound,full,swapped}`，删除无引用的 `need_equip`；
  三处 `stats_desc` 改写为新机制（zh/en 双份）。

### 已知取舍
`ActionIndicator` 单槽 ⇒ 中指 长兄的**角斗士连击 / 狂战士狂暴**会与「切换主副」按钮轮流占位（当前策略：让位给职业技能，
它们 `clearAction` 后下一回合我方接管）。要并存需给 `ActionIndicator` 加第二个槽位（另一个量级）。

### 核验
- 括号全平衡 + UTF-8；**单文件 javac 通过**（EXIT=0，产 8 个 class）。
- 确认空手（`weapon==null`）安全：`RingOfForce.fightingUnarmed()` 在 `attackingWeapon()==null` 时返回 true，
  `Hero.attackDelay()/damageRoll()/hitSound()` 都有此分支保护 ⇒ 剑进副手、主手空出不会崩。
- 未代跑 Gradle，交用户 `build-desktop.bat` 验证。
- 档案：`docs/features.md` 新增「2026-09-14」整节；`AGENTS.md` §4 新增/改写 4 条（锁死槽位、主副对调、ActionIndicator 单槽、defaultAction 自定义快捷栏）。

## 追加2：封印之剑解封形态的屏幕温度滤镜（HeatVignette）

### 需求
装备 一阶段/二阶段/莱瓦汀 时，屏幕分别泛 **黄/橙/红** 半透明滤镜（代表温度升高）；**边缘最强、中央接近透明**；**不遮 UI**。

### 调研结论（关键机制）
- noosa `Group.draw()` **严格按 `add()` 顺序**绘制；`GameScene.create()` 里 `add(cellSelector)` 之后紧接着才是第一件 UI（`add(menu)`）
  ⇒ 滤镜插在这两者之间 → 世界层在它下面着色、UI 全在它上面。**这就是「不遮 UI」的实现方式。**
- 屏幕空间必须自带 `camera = PixelScene.uiCamera`（默认继承 `Camera.main` 会跟着英雄滚动）。
- `Image` **没有 `size()`**；改 `scale`（= uiCamera.width/texW）比改 width/height 省掉 `updateVertices()`。
- 片元着色器 `gl_FragColor = texture2D(uTex,vUV) * uColorM + uColorA`；`hardlight(color)` 是纯乘算 ⇒ 白渐变 + 染色 = 任意颜色色罩。
- 默认混合 `SRC_ALPHA / ONE_MINUS_SRC_ALPHA`；`premultiplied` 字段只存不用 ⇒ 贴图要**非预乘**（RGB 恒白、只让 A 走渐变）。
- `TextureCache.create(key,w,h)` 只建对象（`id==-1`；其 `filter/wrap` 见到未生成会跳过 GL 调用）⇒ 建完直接写 `texture.bitmap` 安全，
  真正上传在首次 `bind()`；断上下文 `TextureCache.reload()` 用同一 Pixmap 重传。Pixmap 是 **RGBA8888（R 在高位）**。
- 场景成员每帧被 `Group.update()` 调用（`GameScene` 未覆写 `update()` ⇒ `Scene.update()` → `Group.update()`）。

### 实现
- 新增 `effects/HeatVignette.java`：64×64 白色径向渐变（`r≤0.2` 全透明 → smoothstep → 1，中心留 `0.05` 底噪），
  `scale` 铺满 uiCamera；色板 `{-,0xFFD24A 黄,0xFF8A00 橙,0xFF2A00 红}`、边缘最大不透明度 `{0,0.40,0.55,0.70}`。
- **拉取式、零钩子**：`update()` 每帧 `SealedSwordBase.swordInHands(Dungeon.hero).stage()` 当目标热度，指数逼近（0.35s）；
  装备/解封/主副对调/读档/换层全自动正确；构造时直接对齐避免每次换层闪淡入。
- `scenes/GameScene.java`：新增字段 + 在 `add(cellSelector)` 后 `add(heatVignette)`。

### 核验
- 9 个文件单文件 javac **EXIT=0**（23 class）；`HeatVignette.java` 括号平衡 + UTF-8；未代跑 Gradle。
- 档案：`docs/features.md` 追加「2026-09-14（补2）」节；`AGENTS.md` §4 图层顺序条目下新增「全屏屏幕空间滤镜怎么做到压住画面但不遮 UI」。
