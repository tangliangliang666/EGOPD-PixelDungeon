## CENSORED 测试武器（物品贴图旋转验证）

**目的**：验证 ItemSprite 在**静态展示**（背包 / 工具栏 / 快捷栏等）下能否用代码旋转。

**调研结论**：基类链 `ItemSprite → MovieClip → Image → Visual`，父类 `Visual` 暴露的 public 字段 `scale / origin / angle / angularSpeed / flipHorizontal` 全部可直接读写，没有禁用也没有拦截；`ItemSlot.item() / ItemSlot.layout() / ItemSprite.view() / ItemSprite.link()` 链路**不重置**这些字段，所以设了就会持久生效。攻防实战用例：`AttackIndicator.java:160` 直接 `sprite.scale.set(PixelScene.align(20f / Math.max(sprite.width(), sprite.height())))`。

### 新增内容

1. **`ItemSpriteSheet.java`**：新增 `CENSORED_WEAPON = xy(9, 9)` + `assignItemRect(CENSORED_WEAPON, 36, 9)`。9 行 9 列是空位，紧跟 WEP_TIER5（行 9 1-8 列）+ WEP_TIER5 后面的 14/15/16 列已被 ZENOS_TURTLE_SPIRAL/POOP_STORY_BOOK/SHARP_BONE_SPIKE 占。
2. **`CensoredWeapon.java`**（新文件）：`extends MeleeWeapon`，tier=4 + HIT_SLASH + 1.0 pitch。数值框架复用 Longsword；image 返回 CENSORED_WEAPON。
3. **`ItemSlot.java`**：新增 `private void applyIconTransform(Item item)`，在 `item()` 两处 `sprite.view(item)` 之后调用；检测到 `instanceof CensoredWeapon` 则 `sprite.originToCenter(); sprite.angle = -45f;`。所有 ItemSlot 子类（背包 / 工具栏 / 快捷栏）自动生效。
4. **`items_zh.properties`**：新增 `items.weapon.melee.censoredweapon.name=CENSORED` + `.desc`。

### 关键经验

- **静态贴图旋转不需要新建 ItemSprite 子类**——直接在 ItemSlot 父类加 hook 一次，所有子类全局生效。
- **`originToCenter()` 必须先调用**：默认 origin=(0,0)（左上角），长条形以左上角旋转会大幅偏移出格子；先 originToCenter() 再 angle = -45 才是绕中心。
- **位置锚点不变**：`width()/height()` 返回原始 frame 像素大小，旋转后视觉可能溢出格——这里格内有 16×16，36×9 长条横向撑出 + 旋转后会斜伸出格角，是预期测试效果。
- **`applyIconTransform` 走的是 ItemSlot 内部 hook**——`Heap` 单独使用 `ItemSprite`（不经 ItemSlot），所以地面上不会自动旋转。如果以后想全场景生效，需要再 hook 一处。

## CENSORED 旋转 bug 修复（2026-09-06 早）

**症状**：用户反馈装备 CENSORED 后：
- 背包内的「其他物品」也会被旋转
- 装备空置图标本身被旋转

**根因**：`ItemSlot.applyIconTransform` 只在 CensoredWeapon 时设 `origin=(18,4.5)` + `angle=-45°`，**进入时从不 reset**。
同一 ItemSlot 实例（Toolbar / 快捷栏 / WndBag 反复复用 sprite）一旦展示过 CENSORED，sprite 字段持久污染，后续 item 或空状态都带着旋转。

**修复**（`ui/ItemSlot.java#applyIconTransform`，行 232）：进入时无条件 reset：

```java
sprite.angle = 0f;
sprite.scale.set(1f, 1f);
sprite.origin.set(0f, 0f);
sprite.flipHorizontal = false;
sprite.flipVertical = false;
if (item instanceof CensoredWeapon) { sprite.originToCenter(); sprite.angle = -45f; }
```

**经验写入 `MEMORY.md`**：「ItemSprite.transform 改造坑」节——Visual 字段持久不消 + frame() 不重置 origin，造就这类时序泄漏 bug。
